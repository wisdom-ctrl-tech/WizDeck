\# WizDeck



Version: 0.1 "Heartbeat"



WizDeck is a laptop-first DJ controller system built for Mixxx.



Instead of imitating physical controllers, WizDeck embraces the strengths of a keyboard and mouse to create an intuitive, efficient DJ workflow.
